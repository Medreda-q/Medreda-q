## About Me
 
I am a first-year **DUT student in Cybersecurity and Information Systems Audit** at EST Tétouan, Morocco — operating at the intersection of offensive and defensive security. My work spans SOC analysis, penetration testing, and network security engineering, with a strong emphasis on building practical, real-world security competencies.
 
I approach security as a discipline that demands both adversarial thinking and systematic defense. On the blue team side, I focus on threat detection, log analysis, and incident response workflows. On the red team side, I engage with vulnerability assessment, exploitation techniques, and CTF-style challenges to sharpen offensive intuition. My infrastructure interests extend to network architecture, traffic analysis, and security hardening.
 
I believe in learning by building — every concept I study is grounded in a lab, a scenario, or a challenge that makes it operational.
 
```
🔵  Blue Team     →  SOC Operations · SIEM · Threat Detection · Incident Response
🔴  Red Team      →  Penetration Testing · Vulnerability Assessment · CTF Challenges
🌐  Networking    →  Network Security · Traffic Analysis · Infrastructure Defense
📡  Protocols     →  TCP/IP · DNS · HTTP/S · SSH · VPN · Packet Analysis
```
 
**Open To:** Cybersecurity Internship · SOC Analyst Role · Junior Penetration Tester · Security Lab Collaborations
